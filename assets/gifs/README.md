# Profile GIF Asset

This directory contains the GIF displayed in the **`./info.sh`** section of your GitHub profile README.

## How to replace the GIF:
1. Choose or download any GIF you like (for example, a favorite football or Cristiano Ronaldo clip).
2. Save it as:
   ```
   assets/gifs/profile.gif
   ```
3. Overwrite the existing `profile.gif` file.
4. Commit and push:
   ```bash
   git add assets/gifs/profile.gif
   git commit -m "feat: update profile gif"
   git push origin main
   ```

No changes to `README.md` are required—the README will automatically display your new GIF!
